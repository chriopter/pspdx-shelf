About

umdlibrary reads the PSP UMD images (.iso, .cso) in one folder, shows what each disc says about itself, and publishes the folder as a PSPDX catalog so a PSP running PSPDX can list and fetch the discs.

What it does not do

  • It is for private LAN use. There is no login, no rate limit, no hardening: never expose it to the internet.
  • It serves plain HTTP. PSPDX reads catalogs over HTTPS with TLS 1.3 only, so a reverse proxy with a certificate the PSP trusts has to sit in front; the catalog is written with that proxy's https:// address (Settings, public URL).
  • It compresses nothing and never changes an image. The one write into the library folder is a rename you ask for, dry run first.
  • It does no background work you did not switch on: the watch folder is off by default, every job is on the Jobs page.
  • It does not know publishers; the SFO has none. You can enter them per disc id in Settings.
